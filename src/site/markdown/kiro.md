# Kiro IDE

## Information

### Introduction

[Kiro](https://kiro.dev/) is an agentic IDE designed to move beyond simple AI coding assistance toward agentic
engineering. It emphasizes spec-driven development, allowing developers to turn natural language prompts into executable
specifications. Kiro is built to handle large codebases using parallel agents that learn from each session.

It is closely associated with AWS and Amazon ecosystem, providing a high-performance environment for modern software
engineering.

### What is it for?

Kiro is used to:

* **Agentic Engineering**: Move beyond simple code completion to autonomous agent-driven development.
* **Spec-Driven Development**: Turn requirements and prompts into executable specs that guide code generation and
  validation.
* **Parallel Agents**: Utilize multiple agents to build and refactor across large codebases simultaneously.
* **Automated Validation**: Find bugs that traditional unit tests might miss by validating code correctness against
  specifications.
* **Context-Aware Coding**: Leverage deep project context for accurate and relevant code suggestions and modifications.

## Key Features

* **Executable Specs**: Prompts are transformed into formal specifications that serve as a source of truth for agents.
* **Parallel Agent Architecture**: Orchestrate multiple agents to perform complex tasks across different files and
  modules.
* **Learning Agents**: Agents improve and adapt based on developer feedback and session history.
* **Model Agnostic**: Supports various models including Claude (Sonnet 4.5) and various open-weight models.
* **Multi-Platform**: Available for macOS, Windows, and Linux.
* **Advanced Tooling**: Includes agent hooks for automation, conversational coding, and natural language generation.

## Getting Started

### Installation

Kiro can be downloaded from the official website for various operating systems:

* [Download Kiro](https://kiro.dev/downloads/)

### Pricing Tiers

Kiro offers several tiers based on credit usage and model access:

* **Free**: 50 credits/month, access to open weight models and Claude Sonnet 4.5.
* **Pro**: 1,000 credits/month.
* **Pro+**: 2,000 credits/month.
* **Pro Max**: 5,000 credits/month.
* **Power**: 10,000 credits/month.
