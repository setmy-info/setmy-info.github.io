## Ultimate Airbus H125 Home Flight Simulator Setup (X-Plane 12)

### Goal

This document describes a high-end home simulator setup for realistically simulating the Airbus H125 (AS350 B3e)
helicopter using X-Plane 12.

The goal is not only visual flying, but to achieve a realistic helicopter control experience:

- Hover training
- Collective management
- Cyclic control
- Pedal coordination
- Mountain flying
- Slope landings
- Autorotation practice
- Realistic helicopter handling

For helicopters, the hardware is often more important than the simulator software itself.

## Simulator Software

### Flight Simulator Platform

Recommended:

- X-Plane 12

Why:

- Excellent helicopter flight dynamics
- Better rotorcraft physics compared to many general-purpose simulators
- Realistic hover behaviour
- Better feeling of:
    - Translational lift
    - Torque effects
    - Tail rotor control
    - Retreating blade effects
    - Autorotation

## Helicopter Model

Use:

- Airbus H125 / AS350 add-on for X-Plane 12

The Airbus H125 is a single-engine turbine helicopter equipped with:

- Turbomeca Arriel engine
- FADEC system
- Sensitive cyclic control
- Collective pitch control
- High-performance mountain flying capability
